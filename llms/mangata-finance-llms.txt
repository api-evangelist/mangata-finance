# Mangata Finance

> Mangata Finance (Mangata X, now rebranded GASP) is a decentralized exchange built as a Substrate parachain in the Polkadot/Kusama ecosystem. It offers gas-free swaps, an omnichain ZK-rollup design, and a Proof-of-Liquidity consensus model. Developers integrate through a TypeScript SDK that communicates with the Mangata Substrate node over Polkadot.js JSON-RPC/WebSocket; there is no REST/OpenAPI surface.
